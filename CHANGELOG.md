# QuietCue Changelog

## 1.1.0 — Simplified presentation flow

- Replaced the five-step workflow with **Setup → Present → Review**.
- Merged deck import, private guidance, timing, and device setup into **Setup**.
- Moved Rehearse, Record, and Live into one **Present** workspace.
- Converted detailed rehearsal pacing into an optional collapsed **Timing plan**.
- Review remains hidden until a recording take exists.
- Live presentations now return to Present instead of opening an empty Review state.
- Older saved Import / Prepare / Rehearse workflow states migrate automatically to the new flow.

## 1.0.0 — Public brand release

### Brand & design
- Renamed the product to **QuietCue**.
- Introduced the **Porcelain / Ink / Iris** visual system.
- Replaced the dark-dashboard aesthetic with a warm premium workspace and dark presentation theatre.
- Reduced decorative badges and persistent chrome.
- Kept advanced controls behind contextual menus and accordions.

### Product experience
- Import → Prepare → Rehearse → Present → Review workflow.
- PowerPoint, Google Slides, PDF, and image sources.
- Session-private guidance with legacy note-cache cleanup.
- Flexible target duration and per-slide pacing.
- Floating/resizable camera and private guidance.
- Camera/mic preflight and audio test.
- Rehearse, Record, and Live Present modes.
- Audience-only view and take review.
- Recording protection and recovery.

### Compatibility
- Existing prototype preferences are migrated where safe.
- Guidance content itself is never migrated or persisted.

Earlier prototype version history is intentionally omitted from the public changelog so this repository starts cleanly at QuietCue 1.0.
