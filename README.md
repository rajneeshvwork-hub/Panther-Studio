# QuietCue

A deliberately simple presentation recorder with private notes.

## What it does
- Opens PPTX, PDF, JPG and PNG presentations
- Visible Camera and Mic on/off controls
- Draggable/resizable camera bubble
- Draggable/resizable private notes panel
- Previous/next slide controls
- Recording timer
- Records the presentation + optional camera + optional microphone
- Private notes are never drawn into the recording
- Downloads the finished recording as WebM

## Run
For the best browser permissions experience, serve the folder over HTTPS or localhost. GitHub Pages works well.

## Browser
Use a current Chromium-based browser (Chrome or Edge recommended).

## Design principle
One screen. One primary action. Advanced workflows intentionally omitted.
